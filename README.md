# 초음파 침입 감지 시스템

Raspberry Pi 4에서 초음파 센서로 한 방향을 감시하다가 거리가 달라지면 LED와 서보로
경보를 울리고, 웹 화면과 CSV 파일에 기록하는 프로그램입니다.

## 동작 방식

1. 웹 화면에서 `감시 시작`을 누르면 30초 후 기준 거리를 학습합니다.
2. 약 0.2초마다 거리를 재고, 정상 범위를 벗어나면 다시 측정해 침입 여부를 확인합니다.
3. 침입이 확인되면 LED가 빠르게 깜빡이고 서보 깃발이 올라가며, `events.csv`에 기록됩니다.
4. 마지막 감지 후 10초가 지나면 감시 상태로 돌아갑니다.

## 배선 (BCM 번호)

| 부품 | GPIO |
|---|---|
| 초음파 센서 TRIG | 20 |
| 초음파 센서 ECHO | 16 |
| 서보 모터 신호선 | 18 |
| LED | 6 |

HC-SR04의 ECHO는 5V 신호이므로 전압 분배 저항을 거쳐 GPIO에 연결하세요.

## 실행

```bash
pip install -r requirements.txt
python app.py                # http://<Pi 주소>:8000
python app.py --arm-delay 10 # 감시 시작 전 대기 시간 변경
python app.py --sim          # 하드웨어 없이 가상 센서로 실행
python -m unittest test_detector
```

## 주의

웹 화면에 로그인 기능이 없으므로 신뢰할 수 있는 네트워크에서만 사용하세요.
초음파 센서는 정면의 좁은 범위만 감시하므로 학습·시연 용도에 적합합니다.
